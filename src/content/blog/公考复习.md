# 资料分析

## 增量公式

### 标准增长量公式

![标准增长量公式](./images/gongkao/标准增长量公式.png)

推导过程：

同比量 = 现期量 / (1 + 增长率)

增长量=  现期量 - 同比量

增长量 = 现期量 - 现期量 / (1 + 增长率) = (1 + 增长率) * 现期量 - 现期量 / (1 + 增长率) = 现期量 * 增长率 / (1 + 增长率)

### 特征数字法*

换算成分数: 增长率r = 1 / n

增长量 = 现期量 / (1 + n)

### 化除为乘

作用域: 在增长率r很小时

同比量 = 现期量 * (1 - r)
